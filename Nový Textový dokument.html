Arch Linux na steroidech

Žádné X11, žádný Wayland, žádný bloatware. Jen čistá TTY konzole s custom linuxovým kernelem a bleskovou odezvou.

// 01

Arch Linux Base

Plná kompatibilita s repozitáři Pacman a AUR. Využijte stabilitu a nejnovější balíčky špičkové distribuce.

// 02

NXT-sh Shell

Předinstalovaný, moderní asynchronní shell s nativním našeptáváním, git integrací a extrémní rychlostí.

// 03

Nulový režijní šum

Systém po startu spotřebovává pouze 512 MB RAM. Veškerý zbylý výkon dává vaší práci, ne těžkopádnému grafickému prostředí.

// 04

Hardware Acceleration

Nativní podpora GPU akcelerace přímo v TTY pro vykreslování tmuxu, terminálové grafiky a multiplexerů.

// 05

Orvi Dev Stack

Předkonfigurované prostředí pro kontejnery (Docker/Podman), vestavěný Neovim s LSP a podpora síťových nástrojů.

// 06

Git-Driven Configs

Celý operační systém se konfiguruje pomocí dotfiles. Záloha, obnova nebo replikace prostředí jedním příkazem z GitHubu.
